## 📌 Tentang Proyek / About the Project

**[ID]** Proyek ini adalah antarmuka pengguna (User Interface) berbasis web statis untuk toko ritel sembako dan kebutuhan harian. Dirancang sebagai landing page e-commerce yang interaktif, aplikasi ini menampilkan katalog produk, kategori belanja, serta ulasan pelanggan dengan desain yang bersih dan responsif.

**[EN]** *This project is a static web-based User Interface for a grocery and daily needs retail store. Designed as an interactive e-commerce landing page, it features product catalogs, shopping categories, and customer reviews with a clean and responsive design.*

---

## 🚀 Fitur Utama / Key Features

**[ID]**
* **Navigasi Dinamis:** Antarmuka interaktif untuk pencarian (search bar), pratinjau keranjang belanja (shopping cart), dan formulir login.
* **Katalog Interaktif (Swiper.js):** Memanfaatkan fitur carousel/slider untuk menampilkan daftar produk dan ulasan pelanggan secara efisien.
* **Desain Responsif:** Tata letak (layout) yang dioptimalkan untuk menyesuaikan dengan berbagai ukuran layar perangkat (Desktop, Tablet, Mobile).

**[EN]**
* **Dynamic Navigation:** Interactive UI components for a search bar, shopping cart preview, and a login form.
* **Interactive Catalog (Swiper.js):** Utilizes carousel/slider functionalities to display product lists and customer reviews efficiently.
* **Responsive Design:** Layouts optimized to adapt seamlessly across various device screen sizes (Desktop, Tablet, Mobile).

---

## 🛠️ Teknologi & Library / Technology & Libraries

* **Struktur & Gaya (Structure & Styling):** HTML5, CSS3 (Vanilla)
* **Interaktivitas (Interactivity):** JavaScript (DOM Manipulation)
* **Ikonografi (Iconography):** FontAwesome (v4.7.0)
* **Library Slider:** Swiper.js (v11)
